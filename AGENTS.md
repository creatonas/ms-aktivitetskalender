# Aktivitetskalender

Les README og PROJECT-PROFILE.md før pluginendringer. Sjekk gren og Git-status; bevar eksisterende arbeid. Kilde er ms-activities.php, includes/ og public/.

Bevar posttypen aktiviteter, shortcodes ms_calendar/ms_activities/ms_activities_toggle, ACF-nøkler og den offentlige AJAX-handlingen ms_load_calendar.

Kjør PHP/JavaScript-syntakskontroll og relevante WordPress/ACF-tester. Flere kalendere, datooverganger, ugyldige inndata, manglende ACF og tastaturbruk er viktige testtilfeller.

Bruk gren og PR. Avklar cPanel-trigger og destinasjon før merge/deploy. Kildearkiv, stabil release og produksjonsdeploy er separate handlinger.
